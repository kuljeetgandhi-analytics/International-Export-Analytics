# International Export Performance & Profitability Dashboard

## Project Overview
An interactive Power BI dashboard built to analyze international export performance and profitability across countries, continents, products, customers, and shipping ports.

## Objectives
- Analyze export revenue, costs, and profit.
- Compare performance across countries and regions.
- Explore product and customer contributions.
- Review shipping methods and port-level activity.
- Identify export trends and profitability patterns.

## Tools & Skills
- Microsoft Power BI
- DAX
- Data Analysis
- Data Visualization
- Business Intelligence
- Dashboard Design

## Dashboard Highlights
- Export performance overview
- Country-wise export analysis
- Continent and regional analysis
- Product export analysis
- Shipping and port analysis
- Export customer analysis
- Export profitability analysis
